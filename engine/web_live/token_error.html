本地服务拒绝了这次请求

HTTP 403：这一页需要带 token 的本地 URL 才能打开。

先核对这三处

  1. URL 没复制全。?token= 后面必须完整。控制台字体里 1 / l / I、_ / - / . 很像，别照着屏幕手敲。
  2. 连到了另一个实例。同一台机器上先后开过两次转写时，旧服务可能还占着这个端口。核对控制台刚打印的端口号，不要用旧标签页的地址。
  3. 服务重启过。token 每次启动都会换；退出程序后旧链接一律失效。



启用 web live 时程序会自动打开页面；也可以双击项目目录里的 open_live.url。此页不显示任何转写内容，也不显示 token。
