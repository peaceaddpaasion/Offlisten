# 品牌与图标

## 那个 ico 是哪来的

`whisper/app_icon.ico`（2026-10-26 10:50）**不是设计产物**，是当天做系统托盘（pystray）时用 PIL
程序化画的托盘图标——深灰圆角方块 + 黄圆 + 蓝条。项目记忆里原话是「图标 app_icon.ico（PIL 生成）」，
它没有 SVG 源、没有尺寸规范、也从没进过设计流程。

v0.1.1 我直接把它提取成扩展图标，是偷懒：它 16px 下就是一个黄点，且与「转写」这个动作没有语义关系。
v0.1.2 起换成下面的设计。

## 四个候选与 16px 实测

真实渲染（headless Edge，按 128/48/32/16 逐尺寸光栅化，不是缩放）：

| 候选 | 形状 | 128/48 | 32 | 16 | 问题 |
|---|---|---|---|---|---|
| A `candidate-a-wave.svg` | 三根声波柱 + 蓝色字幕轨 | 好 | 清楚 | 糊成台阶 | 容易和音量/均衡器混淆 |
| B `candidate-b-lines.svg` | 三行递减文本行 | 好 | 糊 | 糊成一块 | 线太密，小尺寸不可用 |
| C `candidate-c-arc.svg` | 实心点 + 两道扩散声弧 | 好 | 清楚 | 最清楚 | 视觉上是通知/音量图标，语义偏「接收」不偏「记录」 |
| D `candidate-d-frame.svg` | 字幕框 + 框内一句黄条 | 好 | 清楚 | 可辨 | — |

对照图见 `preview.png`（`preview.html` 可重新打开）。

## 最终方案（v0.1.2）

同一套视觉语言，按尺寸给两种构图：

- **32 / 48 / 128**：`icon.svg` —— 深灰圆角底（`#23272c`）+ 浅灰字幕框（`#e8eaed`）+ 框内一条黄条（`#f5c542`）。
  语义：一条字幕，正在说的那一句用品牌黄标出来。
- **16**：`icon-16.svg` —— 去掉框内黄条、把框改成品牌黄、描边加粗到 15/128。
  16px 下黄框是唯一可辨的形状，塞两条细节只会糊。

为什么不统一：16px 的物理像素只有 256 个，字幕框描边按比例只有 1.1px，加黄条后两者互相污染。
分尺寸构图是图标设计的常规做法，不是妥协。

## 重新生成

```powershell
# 换完 SVG 后：按尺寸真实光栅化（需要 Edge），再覆盖 icons/
# 16 用 icon-16.svg，32/48/128 用 icon.svg
```

生成时**必须**带 `--default-background-color=00000000`，否则圆角外会被填成白底，深色工具栏上出现白角。
产出要求 RGBA；RGB 视为失败。四个尺寸都要核对像素尺寸与文件体积，不能只看「生成成功」。

## 名字

内部一直叫 `whisper`，但**引擎不是 OpenAI Whisper**——是 sherpa-onnx + SenseVoice / zipformer。
继续用这个名字有两层问题：事实错误（用户会以为在用 Whisper 模型），以及搜索被 Whisper 生态淹没。

命名约束（按优先级）：

1. 中文 2 字，能念、能搜、不像功能名（`会记` 太像「会议纪要」按钮）
2. 英文 4–6 字母，能注册域名、能当 repo 名与安装包名
3. 不撞现有产品（`Scribe` / `Verbatim` / `Earshot` 都已被占）
4. 语义落在「本地 / 听见 / 逐字留下」三者之一，不承诺云端能力

候选（未做域名与商标查重，**不能直接对外用**）：

| 中文 | 英文 | 语义 | 风险 |
|---|---|---|---|
| 言迹 | Verba | 言语留下的痕迹 | Verba 有同名视频面试产品 |
| 拾句 | Sift | 从声音里拾起句子 | sift 是通用词，商标可能已覆盖 |
| 耳记 | Hark | 倾听 + 记录 | hark 有多家小工具在用 |

**改名是一次跨仓库批量替换**，定名后要一次性改动：

- `whisper-ext`：`manifest.json` 的 `name` / `description` / `action.default_title`、`popup.html` 的 `<title>` 与 `<h1>`、README、安装包名、repo 名
- `whisper`：`run_transcriber.bat`、窗口标题、托盘 tooltip、live/history/meeting 三个页面的 `<title>`、会议 md 头部、`web_live.json` 文件名
- **用户数据路径**：会议存档在 `meetings/`、发现文件是 `web_live.json`。改名若同时改目录，历史会议会「消失」。要么保留目录名，要么写迁移脚本——**这条必须在改名方案里单独决定**。

在定名之前，代码里先不动 `whisper` 标识，避免改一半。
